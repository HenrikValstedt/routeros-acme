Enroll device

  
1. Connect›2. Review & confirm›3. Result

  

  

    

      Enrollment prepares a MikroTik device for hands-off, secure certificate management. Using an administrator
      login once, RouterOS ACME will:
      
    
        
  • secure the device's api-ssl service with a TLS certificate and pin its fingerprint, so the app can't be tricked into talking to an impostor;
    • 
        
  • create a dedicated service account with only the rights needed for certificates. It can't use SSH, Winbox or WebFig, can't manage users and can't reboot;
    • 
        
  • give that account a random 256-bit password that no person ever sees, restrict it to this server's address and rotate it automatically every 30 days;
    • 
        
  • from then on, talk to the device only over the encrypted API. Private keys are uploaded encrypted, too.
    • 
      

    

    

      

      

      

      

    

    

    

    
🔒 These admin credentials are used for this enrollment only. They go straight to the device over SSH and are
      never saved or logged by RouterOS ACME. You can change the admin password afterwards; it won't affect certificate management.
