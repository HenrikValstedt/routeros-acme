# Security policy

routeros-acme holds private keys, DNS credentials and router access, so security reports are very welcome.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately instead:
*Security* tab → **Report a vulnerability** (GitHub private vulnerability reporting).

Include the version (shown in Settings, or the image tag), what you did and what happened. You'll get an answer
as soon as possible, and a fix is released as a new patch version with a note on the release page.

## Supported versions

Only the latest release gets security fixes. To upgrade, pull the new image and recreate the container.
